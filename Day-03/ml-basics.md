# Supervised vs Unsupervised Learning

## 1. Supervised Learning
Supervised Learning ek aisi technique hai jahan model ko labeled data par train kiya jata hai, yani inputs ke sath unke correct answers (labels) pehle se maujood hote hain. Model input aur output ke beech ke mathematical relationship ko seekhta hai taaki naye unseen data ka accurate output predict kar sake. Yeh mainly Regression (continuous numbers) aur Classification (categories) ke liye use hota hai.

### Examples:
1. **Student Exam Result:** Hours studied (input) dekh kar predict karna ki student **Pass** hoga ya **Fail** (known answer).
2. **Spam Email Detection:** Email ka text dekh kar categorize karna ki yeh **Spam** hai ya **Not Spam**.

---

## 2. Unsupervised Learning
Unsupervised Learning me model ko unlabeled data diya jata hai, jahan koi pre-defined answers ya target labels nahi hote. Algorithm bina kisi teacher ke data ke andar ke hidden patterns, similarities aur natural structures ko discover karta hai. Yeh primarily Clustering (groups banana) aur Dimensionality Reduction ke liye use hota hai.

### Examples:
1. **Customer Segmentation:** E-commerce users ke purchase patterns aur browsing time ke hisaab se unhe different buyer groups me baantna.
2. **Music Recommendation:** Spotify par listening habits ke basis par similar songs aur listeners ke clusters create karna.
