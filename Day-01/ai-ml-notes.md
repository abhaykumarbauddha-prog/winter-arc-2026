### Apne Notes / README ke liye Simple 5–10 Lines

1. **Artificial Intelligence (AI):** AI ek bohot bada umbrella term (bada ghera) hai, jiska goal machines ko aisi ability dena hai jisse wo insaano ki tarah soch sakein, seekh sakein ya decision le sakein (chahe wo basic `if-else` rules se ho ya complex math se).
2. **Machine Learning (ML):** ML, AI ka ek hissa (subset) hai. Isme hum computer ko har ek rule manually code karke nahi sikhate, balki use data dete hain aur algorithm khud data ke patterns se seekhta hai.
3. **Deep Learning (DL):** DL, Machine Learning ka ek advance hissa hai jo insani dimaag (Human Brain) ke structure yani **Neural Networks** se inspired hai.
4. **DL ki Specialty:** Jahan basic ML structured data (jaise Excel sheets) par behtar chalta hai, wahan DL complex data jaise images, video, voice recognition aur modern LLMs ko handle karta hai.
5. **How they are related:** Inka rishta **Russian Nesting Dolls (ek ke andar ek dabba)** jaisa hai:
* Har **Deep Learning** model ek **Machine Learning** model hota hai.
* Har **Machine Learning** technique **AI** ke under aati hai.
* Lekin har AI, Deep Learning ya Machine Learning nahi hoti (jaise puraane chess bots jo simple fixed rules par chalte the).
