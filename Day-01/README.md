# Day 01: Git, GitHub & JS Fundamentals

## Topics Covered
- **Git Basics**: `init`, `add`, `commit`, `status`, `push`
- **JavaScript Core**: Variables (`let`, `const`), Data Types, Conditionals (`if/else`), Loops (`for`, `while`)

2. Data types identification and strict comparison (`===`).
3. Grade calculator using conditional branches.
4. Classical FizzBuzz logic using `for` loop.
5. Array element summation using a `while` loop.
